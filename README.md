# Car Price Prediction

A Machine Learning project to predict car prices using Python and Linear Regression.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow

- Data Loading
- Exploratory Data Analysis
- Data Preprocessing
- Categorical Encoding
- Feature Scaling
- Train-Test Split
- Linear Regression
- Prediction
- Model Evaluation

## Model

Linear Regression is used to predict car prices.

## Evaluation

The model is evaluated using R² Score and Adjusted R² Score.
